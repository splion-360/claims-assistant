# Project guidance

- Speak the facts.
- Follow the Python documentation and design conventions in [agent_start.md](agent_start.md).
- In newly created files, add concise one-line comments before non-obvious logic
  or meaningful processing stages so the reader can understand what follows.
  Explain intent, assumptions, or constraints rather than paraphrasing each line.
  Place comments where they aid understanding, not at a fixed line interval, and
  keep them accurate as the code changes.
